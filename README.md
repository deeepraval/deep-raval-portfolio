# Deep Raval — Developer Portfolio

A premium, responsive React + Vite portfolio website.

## Requirements
- Node.js 18+ (Node 20+ recommended)
- VS Code

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:
`http://localhost:5173`

## Build for production

```bash
npm run build
npm run preview
```

## Personalize it

Open `src/main.jsx` and update:

- `profile.email`
- `profile.github`
- `profile.linkedin` if needed
- Education details
- Skills
- Projects
- Experience / certifications if you want to add them

The main visual design is in `src/styles.css`.

## Important
The content in this starter is based on the information available for Deep Raval in the current conversation. Verify exact dates, institution names, grades, certifications and project links against your LinkedIn before publishing.
